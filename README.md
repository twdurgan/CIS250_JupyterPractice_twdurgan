# CIS250_JupyterPractice
This practice assignment is designed to walk you through a simple Jupyter Notebook. Jupyter Notebooks are special code files that allow us to store code and text in the same file. We use this capability to write scripts and descriptions into one organized place. <br>

For this assignemnt:
1. Clone the repo like normal
2. Open the Jupyter Notebook file in Azure Data Studio
3. Complete the notebook
4. Check in changes and submit link to Canvas

There will be SQL script in this notebook that we have not covered, but you do not need to write anything, just edit existing scripts according to instructions.
